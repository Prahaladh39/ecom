CBSE Class 12 Computer Science Project

School Peer-to-Peer E-Commerce System

A full-stack student marketplace application built with Python (Flask) for the front-end application and business logic, and MySQL Database for persistent backend data storage.

Subject: Computer Science (Python & MySQL)
Active DB Engine: {{ db_engine }}
Architecture: Model-View-Controller (MVC)

Implemented Workflow & Requirements

WhatsApp Direct "Buy Now"

When a buyer clicks Buy Now, the application automatically constructs a formatted WhatsApp link (`wa.me/phone?text=...`) directly opening a chat with the student seller with pre-filled item and price details.

Sell Your Product Flow

Top-right button leads to a listing creation form where students can set Title, Category, Price, WhatsApp Phone number, detailed notes, and upload up to 3 real photos with instant preview.

Shopping Cart & Dynamic AJAX

Asynchronous cart additions update the navbar counter badge and trigger toast notifications without disrupting page viewing. Cart calculates grand totals.

MySQL + SQLite Fallback

Connects natively to MySQL Server using `mysql.connector` / `pymysql`. Includes auto-fallback to SQLite so the project runs on any computer without configuration headaches.

Viva Voce Preparation (Q&A for Examiner)

Q1. How does Python connect with the MySQL database in this project?
Answer: We use the mysql.connector module in Python. We establish a connection via mysql.connector.connect(host, user, password, database), create a cursor with cursor = conn.cursor(dictionary=True), execute parameterized SQL queries to prevent SQL Injection, and call conn.commit() for INSERT/UPDATE/DELETE operations.
Q2. How is security handled for student passwords?
Answer: Passwords are never saved in plain text. We utilize cryptographic password hashing using Werkzeug's generate_password_hash() and verify them using check_password_hash().
Q3. How does the "Buy Now via WhatsApp" feature work?
Answer: We use the WhatsApp Click-to-Chat API standard (https://wa.me/[phone]?text=[encoded_text]). Python cleanses the seller's mobile number, encodes an inquiry message with urllib.parse.quote(), and creates a seamless link that opens WhatsApp directly on mobile or web.
